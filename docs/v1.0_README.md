## Achados centrais
- **XGBoost** sobre embeddings da CNN: AUC OVR = 0,768 (melhor)
- **Random Forest**: Acurácia = 68,95%, F1 Macro = 0,291 (melhor F1)
- **CNN fim-a-fim**: colapso preditivo (recall Melanoma = 1,8%)
- Hipótese central confirmada: arquitetura híbrida CNN + classificador clássico supera CNN fim-a-fim em F1 Macro e recall de classes minoritárias.

## Limitação principal
Avaliação interna apenas (holdout 80/20 no HAM10000) — sem validação externa. Esta limitação é exatamente o que motivou o artigo 1.1.
