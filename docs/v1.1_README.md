## Como submeter no Overleaf

1. Crie projeto novo no Overleaf
2. Faça upload de:
   - `artigo_cbis2026_blind.tex` (renomear para `main.tex`)
   - `references.bib`
   - `images/` (pasta inteira)
3. Compile com **pdfLaTeX** (não XeLaTeX — o `mathptmx` exige pdfLaTeX para Times New Roman)
4. Verifique se o PDF gerado:
   - Tem ≤10 páginas
   - Resumo PT/EN com ≤150 palavras cada
   - Citações no formato Vancouver `(1)`, `(2-5)`
   - Termos estrangeiros em itálico
5. Gere relatório de checagem de plágio (ferramenta da sua preferência, ex.: Turnitin, Plagius) — exigência mandatória do CBIS'26

## Limitações reconhecidas no artigo
1. **Viés étnico:** HAM10000 é majoritariamente eurocêntrico (fototipos I-II Fitzpatrick); validação em base brasileira é prerrogativa para implantação no SUS
2. **Viés de aquisição:** imagens dermatoscópicas padronizadas; smartphones na atenção básica introduzem ruído não modelado
3. **Recall insuficiente para autonomia clínica:** mesmo após SMOTE, recall mel = 32,7% é abaixo do limiar para uso autônomo; serve como ferramenta de segunda opinião apenas
