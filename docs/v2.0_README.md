## Objetivo

Construir um dataset brasileiro a partir de dois livros didáticos nacionais (Azulay 2015 + Glossário Ibero-Latino-Americano) e avaliar o modelo HAM10000 (treinado no v1.0/v1.1) nesse novo domínio, medindo:

- **Quanta degradação** o modelo sofre em imagens brasileiras (hipótese: viés étnico-fenotípico do HAM10000)
- **Se o pipeline híbrido** (XGBoost sobre embeddings) preserva sua superioridade no novo domínio
- **Análise por fototipo Fitzpatrick** quando capturável (vantagem dos livros brasileiros vs HAM10000)

## Resultados quantitativos até agora

### Distribuição da base nacional (N=283 imagens HAM-compatíveis)

| Classe HAM | N | % |
|---|---|---|
| mel | 101 | 35,7% |
| bcc | 63 | 22,3% |
| nv | 48 | 17,0% |
| bkl | 39 | 13,8% |
| akiec | 15 | 5,3% |
| df | 14 | 4,9% |
| vasc | 3 | 1,1% |

Origem: **230 do Glossário** (Cap. V Dermatoscopia + Cap. VI Histologia) + **53 do Azulay** (Parte 15 — Neoplasias).

### Achado metodológico: mineração dirigida bate amostragem aleatória

| Estratégia | Taxa de aproveitamento HAM10000 |
|---|---|
| Amostragem aleatória (piloto N=50) | 16% |
| **Mineração dirigida por capítulos tumorais** | **44,8%** |

Causa: livros brasileiros têm cobertura clínica ampla (hanseníase, sífilis, micoses, dermatites). Só capítulos específicos de neoplasias têm densidade alta das 7 classes HAM.

### Análise dos pesos da branch clínica (modelo HAM10000 original)

Análise de **Jacobiano numérico** sobre 2.000 amostras de teste (`scripts/_analise_pesos_finais.py`):

| Feature | Magnitude efetiva (sum \|dY/dX\|) |
|---|---|
| **age** | 2,58 (1º) |
| sex | 1,58 (2º) |
| localization | 1,18 (3º) |
| **Razão age/loc** | **2,18×** |

Camada de fusão (Visual 128 dims vs Clínica 8 dims):
- L2 total: visual 12,91 vs clínica 3,14 (razão **4,1×**)
- L2 por dim: visual 1,14 vs clínica 1,11 (razão **1,03×**)

→ **Cada feature clínica tem peso individual equivalente** ao de cada feature visual. A diferença total vem do volume (16× mais features visuais).

### Experimento: re-priorizar localization (sem retreinar)

Modificamos os pesos da 1ª camada da branch clínica para testar hipótese de "dar mais peso a localização e menos a age/sex". Resultado: **todas as configurações testadas degradaram o desempenho**.

| Config | AUC OVR | ΔAUC vs Baseline |
|---|---|---|
| Baseline (1,1,1) | **0,730** | — |
| Pedido (0.5, 0.5, 2.0) | 0,576 | −15,4 pp |
| Agressivo loc (0.1, 0.1, 5.0) | 0,513 | −21,7 pp |
| Sem age (0, 1, 1) | 0,680 | −5,0 pp |
| Sem clínica (0, 0, 0) | 0,474 | −25,6 pp (abaixo de chute!) |
| Só age (1, 0, 0) | 0,629 | −10,1 pp |

**Conclusões:**
1. O modelo encontrou um equilíbrio fino entre as 3 features clínicas — qualquer reweighting destrói calibração
2. `age` é a feature clínica mais discriminativa (remoção isolada custa 5 pp de AUC)
3. **Sem branch clínica, AUC fica abaixo de chute aleatório** (0,474) — a branch clínica é estrutural, não decorativa
4. Reforça expectativa de degradação na base brasileira, onde 99% das imagens não têm `age` extraível

## Decisões metodológicas-chave

1. **Sem republicação de imagens** — copyright dos livros respeitado, base permanentemente gitignored
2. **Sem re-treinamento** — modelo HAM10000 é usado como extrator de embeddings; classificadores clássicos treinam só sobre embeddings já cacheados
3. **Curadoria assistida por Claude Code** — sem API key separada; classificação interativa em lotes
4. **Filtro de lixo automatizado** — `filter_book_images.py` sinaliza mas não exclui
5. **Imputação de faltantes só no pipeline final** — `metadata_base_nacional.csv` preserva vazios; `evaluate_base_nacional.py` imputa em runtime
6. **`source_page` preservado** — permite validação manual abrindo o PDF na página exata
7. **Mineração dirigida** (capítulos tumorais) em vez de amostragem aleatória — 44,8% vs 16% de aproveitamento

## Limitações reconhecidas (a documentar no artigo)

- **Imagens de livros ≠ imagens reais de paciente** — qualidade de impressão, possíveis artefatos JPEG, ausência de prontuário associado
- **Metadados clínicos esparsos** — capturados: localização 2,1%, idade 0,7%, sexo 0%, fototipo 0% (esperávamos mais — confirmação de que livros didáticos não têm ficha clínica por imagem)
- **N=283** limita poder estatístico, especialmente em classes raras (vasc=3, df=14, akiec=15)
- **Copyright** — impede redistribuição pública do dataset; apenas resultados agregados podem ser publicados
- **Quase todas precisarão de imputação clínica** (age=50, sex=2, loc=13) na Fase 4 — equivale a testar o modelo quase só na branch visual
