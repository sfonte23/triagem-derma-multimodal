# Mapeamento Permissivo: Termos Médicos → 7 Classes HAM10000

Documento de referência para a classificação da Fase 2 (artigo v2.0).
Decisão metodológica: **mapeamento permissivo** — inclui parentes clinicamente próximos para maximizar o N e atender melhor a heterogeneidade dos livros nacionais.

## As 7 classes HAM10000 e termos aceitos

### `akiec` — Ceratose Actínica e Carcinoma Intraepitelial
- Ceratose actínica / Ceratose solar
- Doença de Bowen / Carcinoma intraepidérmico / Carcinoma in situ
- Eritroplasia de Queyrat
- Queilite actínica
- Queratose pré-cancerosa / Queratose pré-maligna

### `bcc` — Carcinoma Basocelular
- Carcinoma basocelular (qualquer subtipo: nodular, ulcerativo, esclerodermiforme, pigmentado, superficial)
- Epitelioma basocelular
- Ulcus rodens
- **NÃO incluir:** Queratoacantoma (vai para `outros`, pois pode regredir espontaneamente)

### `bkl` — Lesões Benignas Queratósicas
- Queratose seborreica (qualquer variante: estuque, dermatose papulosa nigra)
- Lentigo solar / Lentigo senil / Lentigo simples
- Líquen plano like / Líquen plano (lesão isolada)
- Acantoma de células claras (variante de queratose)

### `df` — Dermatofibroma
- Dermatofibroma
- Histiocitoma fibroso benigno
- Dermatofibroma esclerosante

### `mel` — Melanoma
- Melanoma (qualquer subtipo: superficial, nodular, lentiginoso acral, lentigo maligno melanoma, amelanótico, in situ, espitzoide)

### `nv` — Nevus Melanocítico
- Nevo melanocítico (comum, dermal, juncional, composto)
- Nevo congênito (qualquer tamanho)
- Nevo azul (incluindo variante celular)
- Nevo de Spitz
- Nevo de Reed
- Nevo de Sutton (halo)
- Nevo displásico / Nevo atípico
- Sinal / Pinta (termo leigo no livro)

### `vasc` — Lesões Vasculares
- Hemangioma (qualquer subtipo: capilar, cavernoso, plano)
- Angioma rubi / Angioma senil / Angioma estelar
- Granuloma piogênico
- Malformação vascular (focal)
- Telangiectasia (lesão única focal, não condição)
- Lago venoso
- Sarcoma de Kaposi (lesão isolada — limítrofe; preferir `outros` se contexto sistêmico)

## Categoria `outros` (excluir da análise principal)

Não mapear para nenhuma das 7 classes — vai para coluna `dx_inferido=outros`:
- Psoríase
- Vitiligo
- Dermatite (qualquer: atópica, seborreica, de contato)
- Eczema
- Hanseníase / Lepra
- Leishmaniose
- Micoses superficiais / Tinhas
- Condilomas / Verrugas virais
- Herpes / Zoster
- Sífilis (qualquer fase)
- Pênfigo / Penfigóide
- Urticária
- Eritemas (multiforme, nodoso, etc.)
- Acne / Rosácea
- Alopecias
- Onicopatias
- Tumores não-melanocíticos não-cutâneos (sarcomas profundos, linfomas)
- Histologia / dermatoscopia esquematizada / diagramas

## Heurísticas para casos ambíguos

1. **Sem informação clara de dx**: marcar `dx_inferido=""` (vazio) e `confianca=0.0`
2. **Múltiplos dx no mesmo texto**: priorizar o que está mais próximo do "Figura X.Y" exata
3. **Lesão genérica** ("tumor cutâneo", "neoplasia"): vazio, não chutar
4. **Dx fora das 7 classes mas claro**: `dx_inferido=outros`, preencher `dx_original_texto`

## Confiança (0,0–1,0)

- `0.9–1.0`: termo HAM10000 explícito no caption (ex.: "melanoma", "carcinoma basocelular")
- `0.7–0.9`: parente próximo no mapeamento (ex.: "Doença de Bowen" → akiec)
- `0.5–0.7`: inferência por contexto (ex.: capítulo de melanomas, mas sem nome explícito)
- `< 0.5`: chute educado — preferir vazio
