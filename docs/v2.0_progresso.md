# Progresso v2.0 — Fases 0 a 3 concluídas

> Resumo executivo do trabalho realizado até agora na construção da base nacional dermatológica (extração de livros brasileiros + classificação). Para contexto completo, ver [`plano_v2.md`](plano_v2.md).

## TL;DR

- **3.732 imagens** extraídas dos 2 livros (Azulay 2015 + Glossário Ibero-Latino-Americano)
- **595 candidatos tumorais** filtrados (capítulos de neoplasias)
- **283 imagens HAM10000-compatíveis** consolidadas, distribuídas nas 7 classes (mel, bcc, bkl, df, nv, akiec, vasc)
- Pronto para Fase 4: avaliar o modelo HAM10000 nessa base brasileira

## Regras metodológicas aplicadas

### 1. Copyright e ética
- Os livros são protegidos por copyright (Azulay 2015 / Colégio Ibero-Latino-Americano).
- **Uso acadêmico interno apenas:** dataset extraído permanece em `data/base_nacional/` permanentemente **gitignored**. Imagens nunca serão republicadas.
- O artigo final reportará apenas resultados agregados.

### 2. Sem retreinamento
- O modelo HAM10000 (76 MB, `models/modelo_multimodal_final.keras`) **não será retreinado**.
- Usaremos esse modelo apenas como extrator de embeddings na Fase 4.
- Padrão idêntico ao v1.1 — preserva comparabilidade.

### 3. Filtro de lixo (sinaliza, não exclui)
Implementado em `scripts/filter_book_images.py`. Adiciona 4 flags booleanos + um `lixo_score` (0-4) por imagem, sem deletar nada:

| Flag | Critério |
|---|---|
| `lixo_pequena` | largura ou altura < 100px |
| `lixo_uniforme` | desvio padrão de luminância < 12 (imagem em branco) |
| `lixo_escala_cinza` | correlação RGB > 0,99 (diagramas histológicos) |
| `lixo_proporcao_extrema` | aspect ratio < 0,3 ou > 3 (logos, barras) |

Médico ou usuário decide na curadoria — preserva auditabilidade.

### 4. Mapeamento permissivo (termo médico → 7 classes HAM10000)
Documentado em [`mapeamento_permissivo.md`](mapeamento_permissivo.md). Resumo:

| Classe HAM | Termos aceitos |
|---|---|
| `mel` | Melanoma (qualquer subtipo), lentigo maligno |
| `bcc` | Carcinoma basocelular, basalioma, ulcus rodens |
| `akiec` | Ceratose actínica/solar, doença de Bowen, eritroplasia de Queyrat |
| `bkl` | Queratose seborreica, lentigo solar/senil |
| `df` | Dermatofibroma, histiocitoma fibroso |
| `nv` | Nevo melanocítico (qualquer variante), nevo de Spitz/Reed/Sutton |
| `vasc` | Hemangioma, angioma, granuloma piogênico |
| `outros` | Psoríase, hanseníase, sífilis, micoses, dermatites, queratoacantoma, CEC, etc. |

Termos limítrofes seguem regras explícitas no documento (ex.: queratoacantoma → `outros` por poder regredir).

### 5. Imputação de faltantes só no pipeline final
- O `metadata_base_nacional.csv` **preserva campos vazios** quando não há informação.
- A imputação (`age` = 50, `sex` = unknown, `localization` = 13) ocorrerá apenas no `evaluate_base_nacional.py` (Fase 4).
- Mesmo padrão de `evaluate_nova_base.py` do v1.1. Permite auditoria do que era "imputação" vs "dado real".

### 6. Mineração dirigida por capítulos (vs. amostragem aleatória)
Decisão tomada após o piloto inicial — ver achados abaixo.

### Fase 2 — Achado metodológico crítico

**Piloto inicial (50 amostras aleatórias) revelou taxa de aproveitamento muito baixa:**

| Estratégia | N amostras | HAM-compatíveis | Taxa |
|---|---|---|---|
| Amostragem aleatória | 50 | 8 | **16%** |
| Azulay aleatório | 20 | 0 | 0% |
| Glossário aleatório | 30 | 8 | 27% |

**Causa-raiz:** HAM10000 tem 7 classes estritamente **tumorais**. Os livros brasileiros têm cobertura clínica ampla — hanseníase, sífilis, micoses, dermatites — pouco do que está no HAM. **Amostragem aleatória desperdiça 84% do esforço em casos `outros`.**

**Solução adotada — mineração dirigida por capítulos:**

| Faixa | Conteúdo | N filtrado |
|---|---|---|
| Azulay p580-700 | Parte 15 — Neoplasias Cutâneas e Cistos | 161 |
| Glossário p313-471 | Capítulo V — Dermatoscopia | ~280 |
| Glossário p473-560 | Capítulo VI — Histologia da Pele | ~150 |
| **Total dirigido** | | **595** |

Taxa de aproveitamento após mineração dirigida: **44,8%** — quase 3× melhor que aleatório.

Isso significa que o teste vai exercitar essencialmente a **branch de imagem** do modelo multimodal. Limitação a ser discutida no artigo.

## Limitações já identificadas para o artigo

1. **N = 283 é pequeno** — limita poder estatístico mas é suficiente para detectar tendências de degradação.
2. **Imagens de livro ≠ imagens reais de paciente** — qualidade de impressão, artefatos JPEG, sem prontuário associado.
3. **Ausência de fototipo cutâneo** — esperávamos algum bônus do contexto brasileiro, mas nenhuma legenda mencionou Fitzpatrick.
4. **Distribuição desbalanceada** — vasc=3, df=14, akiec=15 são números muito baixos para análise por classe.
5. **Sem metadados clínicos** — modelo será testado quase só na branch de imagem.
6. **Copyright restringe redistribuição** — apenas resultados agregados serão publicáveis.
